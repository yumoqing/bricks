# Hfiller

此控件为容器横向排列时,若宽度过宽,自动填充

## option参数说明

| 参数    | 参数说明 | 类型   | 是否必填 | 可选值 | 默认值 |
| ------- | -------- | ------ | -------- | ------ | ------ |
| baseURI | 数据路径 | String | 是       | ---    | ---    |
| tooltip | 提示     | String | 是       | ---    | ---    |
| css     | 样式     | String | 否       | ---    | ---    |
| csses   | 样式     | String | 否       | ---    | ---    |

此控件为样式排列控件
